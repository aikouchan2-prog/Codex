# Image Sorter & Batch Renamer (Windows向け)

画像を**サムネイルで見ながら並び替え**して、
その順番のままファイル名を**まとめて変更**できるアプリです。

- 例: `IMG_9999.jpg, DSC0102.jpg, AAAAA.png` を
  `photo_001.jpg, photo_002.jpg, photo_003.png` にそろえる

---

## これは何ができる？

- 画像フォルダを開いてサムネイル表示
- ドラッグ＆ドロップで順番変更
- 並び順どおりに一括リネーム
  - プレフィックス（先頭文字）
  - 開始番号
  - ゼロ埋め桁数（001, 002 のような形式）
  - 拡張子を維持するか選択

対応拡張子: `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp`, `.tiff`

## 初心者向け：いちばん簡単な使い方（EXE版）

### 1. EXEを用意する

開発者が配布した `ImageSorter.exe` を使う場合は、インストール不要です。
`ImageSorter.exe` をダブルクリックして起動してください。

> 自分でEXEを作る場合は、このREADME下部の「EXE化」を見てください。

### 2. フォルダを開く

アプリ起動後、`フォルダを開く` をクリックして画像フォルダを選択します。

### 3. 順番を決める

サムネイルをマウスでドラッグし、好きな順番に並べ替えます。

### 4. ファイル名ルールを決める

- **プレフィックス**: 先頭に付ける文字（例: `photo_`）
- **開始番号**: 最初の番号（例: `1`）
- **ゼロ埋め桁数**: 桁数（例: `3` なら `001, 002`）
- **拡張子を維持**: 通常はONのままでOK

### 5. 一括リネーム実行

`現在の並びで一括リネーム` を押すと、並び順どおりに名前変更されます。

---

## 具体例（この設定ならこうなる）

設定:

- プレフィックス: `trip_`
- 開始番号: `1`
- ゼロ埋め桁数: `4`

結果:

- 1番目 → `trip_0001.jpg`
- 2番目 → `trip_0002.jpg`
- 3番目 → `trip_0003.png`

---

## 安全に使うための注意

- **最初はコピーしたフォルダで試す**のがおすすめです。
- ファイル名は実際に変更されます（元に戻す機能は未実装）。
- 名前の重複が起きる場合はエラーで停止します。
- 内部では一時ファイル名を使う2段階処理で、衝突しにくい方式にしています。

## Pythonで実行する方法（開発/確認用）

### 前提

- Windows
- Python 3.10以上（推奨）

### セットアップ

```bash
python -m venv .venv
# PowerShell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 起動

```bash
python app.py
```

## よくある質問

### Q. 並び替えがうまくできない
A. サムネイルの上でドラッグ開始してください。フォルダを開き直すと改善する場合があります。

### Q. 日本語ファイル名は使える？
A. はい、基本的に使えます。

### Q. 元に戻したい
A. 現在は取り消し機能がないため、事前にバックアップ（フォルダコピー）を推奨します。


## これで作る（最短手順）

「とにかく作って使いたい」場合は、Windowsで次だけやればOKです。

1. このフォルダをダウンロード（上の「Download ZIP」手順）
2. 展開したフォルダを開く
3. `build_exe.bat` をダブルクリック
4. 完了後 `dist\ImageSorter.exe` を起動

### 配布用ZIPを作る（他のPCへ渡す場合）

1. `package_release.bat` をダブルクリック
2. `release\ImageSorter_release.zip` が作成される

このZIPをそのまま共有できます。
